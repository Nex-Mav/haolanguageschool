# Hao Language School — Website Redesign

A responsive, Apple-inspired single-page website built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page structure and content
- `styles.css` — layout, typography, responsive styles and animations
- `script.js` — mobile navigation, current year and scroll reveal effects
- `assets/favicon.svg` — simple site favicon

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For a local development server, use VS Code Live Server or run `python -m http.server 8000` in this folder.

## Deploy with GitHub Pages

1. Upload all files and the `assets` folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Important content notes

- The public website currently lists the school phone number as +65 9229 5011 and the address as Blk 329 Ang Mo Kio Ave 3, Singapore 560329. Please verify these details before launch.
- The displayed Google rating (4.9 from 22 reviews) is based on the available public business listing at the time this redesign was prepared. Ratings and review counts can change.
- The two written testimonials are from the school's existing website. They are not represented as Google reviews.
- The Google Reviews button links to the school's Google Maps listing. Individual Google review text is not copied into this project.
- The contact button uses a phone link. No enquiry form or backend has been added.
- Images are loaded from Unsplash and Google Fonts are loaded from Google Fonts, so those visual assets require an internet connection.

Confirm programme details, teacher experience figures, contact information, image usage rights and the review rating with the school. Replace the sample/remote photography with school-approved photographs where possible.
